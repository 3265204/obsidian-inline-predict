# Inline Predict — Obsidian 行内智能补全

[English](README.en.md) · [中文文档](docs/zh-CN/README.md) · [中文使用指南](docs/zh-CN/guide.md)

在 Markdown 编辑器中，用灰色文字预览接下来可能要写的内容。按 **Tab** 接受，按 **Esc** 忽略，也可以只接受一个字词、一句或一行。

Inline Predict 专注于写作时的行内补全。你使用自己配置的 OpenAI-compatible 模型服务；插件负责选择触发时机、限制上下文、复用已有建议，并在本地记录用量。

**当前版本：0.1.0 测试版。**

## 功能

- **原生灰字预览**：基于 CodeMirror 6 装饰，接受之前不修改笔记。
- **光标前后文补全**：同时参考前文和后文，支持多行建议。
- **分步接受**：全部、下一字词、下一句、下一行；中日文的“字词”目前按单个字符推进。
- **自动与手动预测**：根据打字节奏、句段边界和近期请求延迟调整等待时间；默认从 2 个前文字符开始考虑预测，可在设置中调整。
- **缓存与连续复用**：输入与建议一致时显示剩余部分；原始前后文改变后失效。
- **结果检查**：拒绝重复、无效或无法修复的截断结果；可选本地跑题过滤和模型相关性复核。
- **本地诊断**：分别显示预测次数、模型调用次数、输入/输出用量、缓存复用和延迟；区分供应商用量、估算和未知用量。
- **中文 / English 界面**：跟随 Obsidian 界面语言。

## 安装

如果使用发布附件，将 `main.js`、`manifest.json`、`styles.css` 放入：

```text
你的仓库/.obsidian/plugins/inline-predict/
```

重新加载 Obsidian，在 **设置 → 第三方插件** 中启用 **Inline Predict**。

请从 GitHub Releases 下载上述独立附件。GitHub 自动生成的 Source code 压缩包是源码，不是可直接安装的插件包。

## 配置模型

打开 **设置 → Inline Predict → 模型**，填写：

| 配置 | 填写方式 |
| --- | --- |
| API 地址 | OpenAI-compatible 服务的基础地址，例如 `https://api.openai.com/v1`；不包含 `/chat/completions` |
| API Key | 服务商提供的密钥；免密本地服务也需要填占位值，例如 `local` |
| 模型 ID | 服务商支持的具体模型 ID |
| 推理强度 | 默认不发送此参数；仅在服务商支持时设置，具体值以服务商说明为准 |

点击 **测试连接**，成功后回到笔记输入。连接测试只发送固定短提示，不包含笔记内容；显示的是一次完整请求的往返耗时，包含服务端处理时间。

模型配置改变会立即清除旧候选和缓存，旧请求的迟到响应不会再显示。没有配置密钥或模型时，不发送补全请求。

## 使用

| 操作 | 效果 |
| --- | --- |
| 停顿输入 | 满足上下文条件时自动预测 |
| Tab | 接受全部灰字；无建议时保留原生行为 |
| Esc | 忽略建议；无建议时保留原生行为 |
| 命令：立即预测 | 手动预测，可为命令设置快捷键 |
| 命令：接受下一个字词 / 句子 / 行 | 只插入对应部分，保留剩余灰字 |
| 命令：切换行内预测 | 开关补全 |

中文输入法组合输入期间暂停显示和接受建议。界面提供触控接受入口，但移动端尚未真机验证。更多设置、排错和日文测试说明见[使用指南](docs/zh-CN/guide.md)。

## 隐私与费用

- 配置并启用补全后，光标附近的笔记内容会发送到你选择的模型服务，受到上下文预算限制。
- 可疑结果启用模型相关性复核时，可能再发送一次包含少量上下文和候选的请求。
- **API Key 以明文保存在插件的 `data.json` 中**。同步或分享 Obsidian 配置目录时请注意这一点。
- 统计仅保存在本地内存，重启后重新计数；没有遥测上传。
- 拒绝、取消或丢弃建议不代表服务商没有计费。诊断会保留已知用量，并明确显示用量未知的调用。
- 不会扫描或上传整个笔记库。

## 已知限制

- 采用非流式生成，完整建议返回后一起显示。
- 多行灰字的换行布局可能与实际插入后的文本略有不同。
- Token 预算使用启发式估算，服务商返回的 usage 才是实际用量依据。
- 跑题过滤只覆盖特定短中文上下文；不保证事实正确，也没有完整日语分词。
- Windows、Linux、iOS、Android 及最低 Obsidian 版本尚未完整实测。`isDesktopOnly: false` 表示代码遵循移动端约束，不是兼容性保证。
- 目前没有路径排除列表。处理不希望发送给模型的笔记时，可以先关闭补全。

## 反馈

反馈问题时请附 Obsidian 版本、系统、编辑模式、模型服务和复现步骤。不要附 API Key 或私密笔记原文。配置、统计与排错说明见[使用指南](docs/zh-CN/guide.md)。
